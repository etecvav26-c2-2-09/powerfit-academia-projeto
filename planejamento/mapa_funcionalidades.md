# ⚙️ Mapa de Funcionalidades (Features)

Para entregar uma excelente experiência de usuário (UX), o site da Academia PowerFit contará com as seguintes funcionalidades técnicas:

## 🎛️ Funcionalidades de Interface (UI)
* **Menu Hambúrguer Responsivo:** No mobile, o menu se esconde para priorizar a tela. No desktop, ele se expande horizontalmente.
* **Efeito Hover nos Cards de Planos:** No computador, ao passar o mouse sobre um plano, o card ganha destaque (zoom leve ou borda iluminada) para incentivar o clique.
* **Carrossel de Fotos (Galeria):** Exibição otimizada das fotos da academia que desliza com o dedo no celular.

## ⚡ Funcionalidades de Conversão
* **Botão Flutuante do WhatsApp:** Um ícone fixo no canto inferior direito que acompanha a rolagem da página, permitindo tirar dúvidas a qualquer momento.
* **Formulário de Contato Validado:** Campos simples (Nome, E-mail, Dúvida) com validação básica no HTML para evitar envios vazios.
