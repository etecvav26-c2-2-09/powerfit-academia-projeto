# 🗺️ Arquitetura de Informação — PowerFit

A estrutura de navegação do site foi planejada de forma linear para garantir que o usuário encontre o preço e o botão de matrícula o mais rápido possível.

## 🌲 Mapa do Site (Sitemap)

```
[Home]
 ├── [Banner Principal / Chamada para Ação]
 ├── [Destaques da Infraestrutura]
 ├── [Modalidades]
 │    ├── Musculação
 │    ├── Crossfit
 │    └── Ritmos / Dança
 ├── [Planos & Preços]
 │    ├── Plano Mensal
 │    ├── Plano Semestral
 │    └── Plano Anual
 └── [Contato & Localização]
      ├── Horários de Funcionamento
      ├── Endereço com Mapa
      └── Formulário de Dúvidas
```

## 📱 Fluxo de Leitura (Mobile First)
No celular, o conteúdo aparecerá estritamente nesta ordem para garantir que o usuário veja o valor do serviço antes de chegar às formas de contato.
